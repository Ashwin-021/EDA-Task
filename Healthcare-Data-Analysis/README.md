# 🏥 Healthcare Data Analysis

## 📌 Overview

This project analyzes healthcare patient data to identify patterns in **patient demographics, medical conditions, admissions, billing, and hospital stays** using Python.

## 📂 Dataset

* **File:** `healthcare_raw.csv`
* **Records:** 500
* **Columns:** 9

### Main Columns

`Patient_ID`, `Gender`, `Age`, `Medical_Condition`, `Admission_Date`, `Admission_Type`, `Medical_Code`, `Billing_Amount`, `Discharge_Date`
